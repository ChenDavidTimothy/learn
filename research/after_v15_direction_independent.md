# Direction critic after continuous-history v15

Date: 2026-10-20. This is a proposed next question, not a claim that v15 has finished or a prescription to build an uncertainty architecture. No canonical experiment was changed.

If ordinary raw histories and polynomial filtering work, and selected history usually equals fixed H4, accept that conventional sufficiency. More lags/kernels/derivative filters would mostly resolve numerical choices inside an already supplied observation vocabulary. The next uncertainty is what the system does when its carefully acquired knowledge stops supporting decisions during actual experience.

## Preferred question: useful repair during an ongoing task

Can the learner reuse past experience and repair a consequential failure with the interactions available while pursuing a goal, without an experimenter announcing the failure or furnishing a new calibration dataset? Current v15 pays for broad independent acquisition upfront; the experimenter supplies all coverage and selects the model menu. It has not shown that the learner can recognize an unsupported decision, obtain useful contrary evidence and revise how experience controls action.

The smallest meaningful test uses the same coupled instrument, sustained goal schedule and position/action information. After a common initial acquisition, apply an unannounced bounded change to body/actuator consequences during operation, with no reset and no change-time input to ordinary controllers. Start with ordinary positive gain/load changes, not an artificial sign flip chosen to defeat stable feedback. Retain a later return to the original condition only if reuse versus destructive overwriting becomes the central uncertainty; do not turn the first study into a large context taxonomy.

Freeze the change distribution and unseen goal schedules before testing. Change times should vary independently of goal switches, so clock/goal metadata cannot identify the condition. At least some changes should happen while holding a goal. A change that has no effect while torque/motion is zero cannot be detected from those observations: a detector is not at fault for lacking an impossible early warning. Necessary excitation can arise from the next useful goal action itself; explicit probing is not automatically beneficial.

Begin with three serious same-information competitors: frozen v15 control; ordinary continuously updated regression/control with a prescribed bounded memory or forgetting rule; and robust causal filtered feedback using no online model repair. Tune ordinary settings using allowed pre-change data or a separate declared development distribution, not the scored hidden changes. If robust feedback already matches the learned systems, report that learning this change was unnecessary for these tasks. Do not manufacture a harsher fault solely to force an adaptive-learning victory.

Score a fixed number of real ongoing control transitions, including every probing/recovery action and its tracking/effort cost. Nobody gets free reset trials, extra settling time or true change labels. Report integrated task cost, time in large error, failures and retained competence, not only post-hoc next-step fit. If adaptation succeeds, evaluate whether it repairs new-goal consequences, rather than merely explaining already seen residuals.

Only add active discriminating actions if ordinary task-driven updating leaves a reproducible ambiguity that affects future decisions. Compare such actions with equal-cost random dither and ordinary goal pursuit on the SAME real interaction/time budget. Any explicit uncertainty ensemble, change detector, experiment design or latent-context memory must earn its complexity in this comparison. This route does not assume exploration, prediction or world models are universal foundations; the observable requirement is that experience changes useful behavior under a limited opportunity budget.

The falsifiable outcomes are straightforward: (a) fixed robust feedback is sufficient; (b) ordinary online updating repairs the task without special exploration; (c) special evidence acquisition improves total task performance after charging its cost; or (d) none succeeds despite feasible tasks, identifying a concrete knowledge/decision failure. Each changes the mechanism we should construct. An isolated detection theorem or improved gain estimate does not.

## A genuinely different alternative, worth keeping open

Remove the supplied encoder semantics instead: expose an unknown invertible sensor-coordinate transformation, with goals expressed in the same observed coordinates, while preserving the physical body and interaction opportunities. No information is lost, but the current Fourier/periodic/velocity-like feature vocabulary may become inappropriate. This directly tests reliance on experimenter-chosen coordinates rather than memory length.

The difficulty is scientific fairness: nonlinear coordinate changes also change approximation complexity, noise law and the numerical meaning of Euclidean goal error. A transportable task metric/physical success criterion and common observation-only information must be fixed explicitly; otherwise apparent learning failure is a changed task or corrupted information. A strong generic nonlinear baseline is mandatory. This alternative may be more foundational than another dynamics change, but it is not automatically the smaller clean next experiment.

## Drift criterion

The next milestone should demonstrate acquired/revised competence or a decisive limitation that changes a general learner's design. Choose one of the above uncertainties and one bounded experiment. Do not publish a ladder of delay, covariance, detector or parameter-identification refinements whose only effect is to improve this two-link benchmark. Established simple methods remain genuine candidates for the mechanism, and their sufficiency is a valid result.
