# Retained local predictor implementation note

2026-10-20. `cartesian_stream_v17_local.py` implements only the frozen local-regression interface. No ordinary corpus, evaluator data, validation selection, forecast test or control run was opened/executed for this implementation.

`LocalPredictor(context_train, command_train, target_train, neighbors, ridge)` takes already standardized66-dimensional contexts, commands already scaled by.5, and already normalized four-coordinate corrections. Constructor arrays are copied so bootstrap members retain independent libraries. `fit(query_context)` returns a69x4 coefficient matrix and JSON-serializable diagnostics. Candidate designs are `[1, standardized_context-query_context, command/.5]`; the module does not rescale inputs again. `append(context, command, target)` retains one new real causal row in the same fixed scale system.

Distance is the sum of mean squared standardized differences over blocks0:2,2:34,34:66. Stable sorting selects the requested nearest contexts (or all available rows if fewer). Weights are exp(-distance_squared/max(kth_distance_squared,1e-12)), normalized to sum1. Weighted normal equations add ridge to68coefficients and leave the intercept unpenalized. All four outputs and both command coordinates are fitted jointly with their full context coefficients; no physical response matrix or plant/evaluator import exists. Diagnostics retain neighbor indices/weights, distance/effective-neighbor summaries, weighted residual losses, penalized objectives and normal-equation residual.

Verification: module byte-compiles. `check_cartesian_stream_v17_local.py` uses only synthetic numerical fixtures. An independently constructed weighted residual-augmentation least-squares solve agrees with the normal-equation coefficients to3.59e-14 and weights to2.61e-18; maximum normal-equation residual9.72e-16. Exact tied zero-distance fixtures verify stable ordering, numerical bandwidth floor, an unshrunk constant intercept and retained append update; intercept/append discrepancy0. Constructor ownership is checked. Actual numerical records/source hash are in `check_cartesian_stream_v17_local_results.json`.

These are implementation checks, not independent research verification, trained results or evidence that the local mechanism suffices. Another auditor should review the weighting/normalization, feature ordering and causal append use when integrated with the common pipeline.
